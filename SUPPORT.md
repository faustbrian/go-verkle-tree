# Support

Use [GitHub Issues](https://github.com/faustbrian/go-verkle-tree/issues/new)
for reproducible defects, documentation gaps, and bounded feature proposals.
Include the module path and version, Go version, platform, minimal reproduction,
expected behavior, actual behavior, and relevant non-secret logs.

Use [GitHub Discussions](https://github.com/faustbrian/go-verkle-tree/discussions)
for adoption questions and design exploration. Consult the
[adoption FAQ](docs/adoption.md#faq), [usage guide](docs/usage.md), and
[storage operations](docs/storage-operations.md) before opening a request. Use
the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities.

The latest stable `v1` release receives support for its documented Go API.
Older releases and the `main` branch are not supported; upgrade before filing
a request. Support does not make the research cryptographic profile suitable
for production. The supported release contract is defined in
[`COMPATIBILITY.md`](COMPATIBILITY.md).
